# 弾き語りリールエディター

弾き語り動画を、Instagram リール向けの縦動画（1080×1920）に編集するブラウザアプリです。
`index.html` 1ファイルで動き、インストールやサーバーは不要です。動画はブラウザ内だけで処理され、どこにもアップロードされません。

## 使い方

1. `index.html` を Chrome または Safari で開く
2. 動画をドラッグ＆ドロップ（またはクリックして選択）
3. 「テーマ」で雰囲気を選ぶ
4. 「歌詞」タブで歌詞を貼り付け →「タップ同期」で、各行を歌い出した瞬間にスペースキー（または TAP ボタン）
5. 「書き出し」タブで範囲を決めて書き出す

## 主な機能

- **レイアウト**：横動画をカード状に配置（元の比率 / 1:1 / 4:5 / 3:4）、全画面切り抜き
- **背景**：動画ぼかし / 動くグラデーション / 単色 / 画像
- **歌詞**
  - レイアウト：下に字幕 / 画面いっぱい / 左寄せ / 縦書き / 流れる歌詞
  - 出方：ぼかしから浮かぶ、下からせり上がる、1文字ずつフェード、字間が広がる、ズームイン、カラオケ、ネオン など13種
  - サビ（行頭に `★`）は別の見せ方に。映像を暗く・ぼかして歌詞を全面に
  - 英詞の訳は行末に `（ ）` で書くと、改行して小さく表示（例：`Stay with me（そばにいて）`）
  - 見せ方プリセット8種
- **音質**：低音ノイズカット、4バンドEQ、コンプ、リバーブ、音量、フェードイン/アウト（プリセット6種）
- **演出**：曲名、冒頭フック、音に反応するビジュアライザー、プログレスバー、色調・周辺減光・フィルム粒子
- **書き出し**：MP4（対応ブラウザ）/ WebM、カバー画像（PNG）保存

## 注意

- 書き出しはリアルタイムで行われます（90秒の動画なら約90秒）。書き出し中はタブを前面に表示したままにしてください。
- 設定と歌詞のタイミングはブラウザ（localStorage）に保存されます。端末間では共有されません。
- 「人物切り抜き（β）」は MediaPipe のモデルを CDN から読み込みます。
